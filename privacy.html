Privacy Policy: Email Priority Digest

Email Priority Digest is a personal tool used only by the owner of the Google account that authorizes it. No other users are supported.

Data accessed

  • Gmail (read): recent messages are read to identify obligations and deadlines.
  • Gmail (modify labels): if the owner enables archiving, messages that have been processed are archived (removed from the inbox). Messages are never deleted.
  • Gmail (send): used only to send the daily summary to the account owner.
  • Google Calendar (events): used to create, update or remove reminder events that the tool itself created.
  • Google Drive (app data folder only): stores a small state file used to avoid duplicates. It cannot see any other Drive files.

Processing and sharing

Email text is sent to Anthropic's Claude API solely to classify and extract obligations. Data is not sold, shared with anyone else, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The tool keeps only short summaries of tracked items, for a few weeks at most. Access can be revoked at any time at myaccount.google.com/permissions.
